# Weekly decision framework

How the agent turns research into **buy / hold / skip** for Niloo.

> Not financial advice. Rules for the research agent.

## Decision hierarchy (never invert)

```text
1. Allocation policy   (~90% core + ballast, ~10% risk sleeve)
2. Market regime       (rates, oil, VIX, breadth)
3. Fundamentals        (earnings path, balance sheet, catalyst quality)
4. Price context       (extended vs pullback; crowding)
5. Attention           (Google Trends / X — sensors only)
```

Attention never upgrades a bad fundamental into a core buy.

## Three decision buckets

| Bucket | Question | Default action |
|--------|----------|----------------|
| **Core** | Am I still funding the plan? | Always yes unless liquidity emergency |
| **Sleeve** | Is there asymmetric quality or a clean theme? | Small adds with size caps |
| **Skip** | Is this a chase / hype / wrong sleeve? | Explicit “leave alone” every week |

## Canada-aware core (default)

| Sleeve | Vehicles |
|--------|----------|
| Canada equity | VCN / XIC |
| US equity | VFV / VUN (CAD-listed) or VTI |
| International | XEF / VIU / VXUS |
| Ballast | Short CAD bonds; avoid loading long TLT when 10y hostile |
| FX note | Always mention CAD/USD when discussing US names |

## Risk sleeve rules (~10% of total)

| Type | Max per name | Examples |
|------|--------------|----------|
| Quality mega-cap | 2–3.5% | GOOGL, MSFT, META (on dips) |
| Theme satellite | 0.5–2% | CEG/CCJ, COPX/TECK, SU/XLE, SMH/MU, ITA |
| Speculative biotech | ≤1.5% | CMPS |
| Combined sleeve | ~10% (trim >12%) | — |

Prefer **bottleneck themes** (power, copper, memory basket) over single parabolic tickers.

## Scoring (0–5) — promote only if Fit ≥ 3

| Factor | 5 means |
|--------|---------|
| Fundamental setup | Clear earnings/catalyst path |
| Risk fit | Liquid, sizeable, matches sleeve |
| Crowding | Not euphoric / FOMO-only |
| Theme durability | Multi-quarter bottleneck, not 1-day headline |
| Attention (bonus) | Trends/X rising with informed context |

**Promote to “buy”** only if fundamentals + risk fit are strong.  
**Promote to “tiny/tactical”** if theme is real but price is extended.  
**Skip** if chasey, illiquid, leveraged, or breaks size caps.

## Every Friday must include

1. One-sentence verdict  
2. Explained shopping list (what / why / how much / what could go wrong)  
3. Skip list with reasons  
4. World-theme scan (oil, AI hardware, AI power, copper, defense)  
5. What worked / didn’t vs prior week  
6. Look-ahead calendar (Fed, earnings, geopolitics)

## Bear case rule

Every ticker in the shopping list gets **one sentence** on what kills the thesis. No cheerleading-only lists.

## Learning loop

Next Friday, score prior “buy” nudges:

| Tag | Meaning |
|-----|---------|
| Hit | Directionally right within 1–4 weeks |
| Miss | Wrong or stopped out by thesis break |
| Early | Thesis OK, timing early |
| Wrong-regime | Idea fine, macro regime wrong |

Store tags in the digest “Learning” footer when possible.
