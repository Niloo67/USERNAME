How to run this centre

  1. Keep this app running on the main desk computer (`npm start`).
  2. Buy a 2D USB QR scanner (not 1D laser). Plug it in — it types like a keyboard.
  3. Open this page on the desk browser and leave the Scan tab ready.
  4. Other phones/tablets on centre Wi‑Fi can open the same address for a live “who is here” list.
  5. Add SMTP details in the server `.env` file to enable parent emails (Gmail App Password works).
  6. Backup: copy data/kumon.sqlite or export CSV from Logs.
