    Franchise baseline checklist

    1. Digital system — This app is the centre’s digital check-in/check-out (not paper/Excel as the baseline).
    2. Unique student ID — Each student has a unique code (and RFID/NFC tag (or student ID)).
    3. Actual arrival/departure — Scan/tap at the desk when the student arrives and leaves (do not backfill later).
    4. Staff oversight — Train staff using the SOP below; use the Staff PIN for roster, logs, and settings.
    5. Who is here + history — Desk “Who is here” list; Logs page for historical review/export.
    6. Backup — Use “Create backup now” and copy data/backups/ off this laptop weekly. Paper sign-in only if the laptop is down.
    7. PII — Parent contact is PIN-protected; desk scan screen does not show parent phone/email.
    8. Retain ≥ 2 years — Logs are never auto-deleted; keep database + backup copies for at least two years.

    How to run this centre

    1. Keep this app running on the main desk computer (npm start).
    2. Plug in the USB 125 kHz RFID reader (keyboard mode).
    3. Open the Tap tab and leave it ready. Set the Windows clock correctly.
    4. Other devices on centre Wi‑Fi can open the same address for a live “who is here” list (no parent PII).
    5. Change STAFF_PIN in .env from the default 1234.
    6. Add SMTP details in .env for parent emails (optional).
    7. Weekly: create a backup and copy data/backups/ to USB/cloud.

    Full staff procedure: see STAFF_SOP.md in the project folder.
