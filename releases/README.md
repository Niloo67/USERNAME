# Releases

One folder per platform release:

```text
releases/
  _templates/
  YYYY-MM-DD-codename/
    manifest.md
    alm.json          # optional Agile LM export
    YYYY-MM-DD-pulse.md
    YYYY-MM-DD-go-nogo.md
    post-release.md   # after launch
```

Copy `_templates/manifest.md` to start. Point the agent at the folder name.
